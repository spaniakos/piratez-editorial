== Changelog ==

= 1.4.0 =
* Itineraries, one-time map permission with consent withdrawal, glossary, print, reading preferences and optional reviewer workflow.
* Includes 1.0 extraction/writing foundation, 1.1 visual tools, 1.2 product showcases and 1.3 maintenance/navigation, developed as separate milestone commits.

== Installation ==
Requires WordPress 7.1.3 and PHP 8.3. Manager is optional.
With PirateZ theme 1.3.x, use migration mode to import settings, then update the theme to 1.4.0.
Catalogue and review workflow are off by default. Existing content/settings survive deactivation.
